# 项目优化记录

本文汇总本轮已完成的工作流、画布、识别、投屏与用户体验优化，并记录验证范围。运行入口、安装及验收命令见 [中文说明](../README.zh-CN.md)。

## 前端使用体验

| 使用环节 | 完成内容 | 用户收益 |
| --- | --- | --- |
| 开始编排 | 步骤卡片提供用途说明、中文用途搜索、单击/键盘/拖动添加；空流程提供常用入口 | 降低双击等隐藏操作带来的学习成本 |
| 添加和定位 | 新节点落在当前视口，自动选中并展开检查器；限制新增时的过度缩放 | 添加后看得见、找得到设置位置 |
| 理解流程 | 可折叠连线图例、快速上手和快捷键帮助；说明移动位置不改变执行顺序 | 明确顺序、依赖、模板分支和返回的区别 |
| 填写参数 | 识别目标与成功后动作优先展示，重试和高级偏移按需展开；非默认配置可发现 | 减少长表单的阅读负担 |
| 输入纠错 | 数字就地校验类型、范围、有限数及区域尺寸；非法值不提交，修正后清除提示 | 避免 NaN、错误次数和越界设置被静默写入 |
| 模板选择 | 加载失败重试、空列表引导、文件缺失提示、创建/管理入口 | 知道缺什么，以及下一步如何解决 |
| 运行反馈 | 状态栏展示保存、连接、当前运行和失败信息，可定位步骤；运行中仍可选择查看 | 不必只靠日志寻找运行位置 |
| 恢复操作 | 应用内命名和删除确认弹窗，焦点管理、Esc 取消；删除撤销提示 | 操作更一致，误操作更容易恢复 |
| 快捷键 | 输入框内 Ctrl/Command+S 先提交字段再保存；弹窗期间阻止画布编辑快捷键 | 避免浏览器另存为或误删背景节点 |
| 日志阅读 | 满容量继续跟随；向上查看历史保留行锚点；提供回到最新入口 | 阅读旧日志不被新消息打断 |
| 小窗口 | 画布可收缩、工具栏换行、日志高度适配；检查器切换节点回到顶部 | 关键控件可达，减少裁切 |

## 画布与编辑性能

- 拆分拓扑、字段、坐标、运行状态更新。普通参数编辑不调用全图构造，也不先清空所有边。
- 节点与边按 ID 复用，只有新增或连接点发生变化的节点重新测量。
- 修复 Vue Flow 在保存锁定时重新校验已有边导致的丢线；新连接继续进行权限和语义校验。
- 多选拖动一次提交所有最终位置，统一更新泳道边界，一次持久化。
- 运行状态使用有界变更记录、步骤到可视节点及相邻边索引，普通步骤事件不扫描全图。快照、重置及变更记录溢出仍能完整同步。
- 日志采用不可变条目与 raw 数组替换，有界去重；折叠或页面隐藏时不渲染日志行、不格式化时间。
- 历史只保留序列化快照，撤销与重做共享 16 MiB、50 条预算。单个快照超限时保留最近一步，作为明确例外。
- 保存只更新已保存基线，不清空历史；延迟保存和重连响应不会覆盖较新编辑。
- 配置与已加载布局一起恢复，避免撤销时删除历史快照中尚未加载预设的本地布局。
- 主流程与分支混选复制/删除统一为一次事务，整体映射 ID、依赖和返回目标；选父步骤时不重复复制子步骤。
- 普通字段编辑跳过无关依赖归一化，并保留未变化字段引用；重复布局及无变化操作跳过存储写入和历史记录。
- 模板目录合并并发请求，短时复用并在写入/导入后失效；模板管理每页最多渲染 60 张卡片。

## 工作流执行与后端可靠性

- 引擎直接发布步骤、轮次、执行帧进入/退出及跳转事件；正式运行状态不再依赖展示日志的中文内容。日志解析仅保留给旧注入引擎的兼容路径。
- 事件携带服务、运行、执行帧标识及序号；重连回放展示数据后发送权威状态快照，前端去重并过滤迟到消息，支持服务重启后的新序号纪元。
- 普通进度增量传输，完整节点状态用于 HTTP 状态、订阅快照及运行完成，不随每步重复传输。
- WebSocket 队列与待调度事件有界，慢消费者断开重连；空闲断连及时清理。
- 事件发布先复制一次获得所有权，再共享给只读消费者；公开快照和内部节点状态继续隔离。
- 配置读改写与启动准入使用同一事务边界，避免并发修改丢失或运行期间更新模板。
- 配置保存采用同路径串行访问、唯一临时文件、刷新落盘和原子替换；失败清理临时文件。
- 上传按流累计限额，图片处理、ZIP、关联 ADB 等同步重任务移到线程池，不持线程锁跨 await。
- 修复回跳重试成功后依赖仍被标记跳过的问题，以及嵌套失败后的状态归属。
- 参数在设备动作前统一校验；全部模板匹配遇到缺失资源明确失败，避免匹配条件被静默削弱。
- 截图、匹配、连击和重试动作之间检查停止，避免请求停止后再发起下一次点击或滑动。已经执行中的单条 ADB 命令仍受原有超时约束。
- 设备尺寸短时复用 0.5 秒并合并并发查询；截图始终实时，断线或错误清缓存，导入强制刷新尺寸。前端设备检查也合并并发请求，运行准备阶段避免重复点击。

## 图像识别与资源

- 新增线程安全模板 LRU 缓存，最多 128 条、64 MiB，按规范路径、纳秒修改时间和文件大小失效；删除、损坏及覆盖不复用旧数据。
- 模板颜色/灰度结果不可写，普通图片加载保持可编辑；每张设备截图只转一次灰度供多个模板复用。
- 保持既有空间优先选择语义，修正 CUDA 匹配器的截图/模板参数顺序。
- 新增可选 ROI 搜索，默认全屏；使用设备原始像素与不含右下边界的矩形，结果还原为全屏坐标，非法或屏外区域明确失败。
- 归档缩放按矩形两端边界处理 ROI，支持嵌套步骤，拒绝缩放后空区域。
- 模板引用一次遍历建立索引并按步骤去重；尺寸与缩略图有界缓存，文件变化失效，缩略图提供 ETag 重验证与前端版本 URL。

## 投屏链路

- 支持 WebCodecs 的浏览器直接接收 H.264 压缩包并解码；只有 JPEG 客户端订阅时后端才创建共享解码/转码路径。
- 保留 JPEG 兼容接口，不支持、协议或解码失败时自动回退；过载有界重同步。
- 订阅队列有界，丢包后等待关键帧并重发配置，不任意丢弃 delta 包后继续解码。
- 缓存当前 GOP，最多 120 包或 8 MiB，支持静态画面晚订阅与 JPEG 回退起播；配置或分辨率变化清理旧缓存。
- 每轮分发只编码一次普通包/关键帧启动包，各订阅共享不可变字节。
- 首帧超时按每个订阅创建时间计算；闲置关闭在锁内重新确认无订阅者，避免误关刚加入的客户端。
- 停止时释放 fetch、reader、decoder、VideoFrame、rAF 与计时器；支持流分包、分辨率切换和 PTS 处理。

## 兼容与验证边界

- 保留旧配置迁移、默认全屏识别、JPEG 投屏端点以及步骤注册/自动生成字段编辑器模式。ROI 缺省关闭，不要求迁移已有用户配置。
- 源码使用者需重启后端并刷新项目页面；分发版需要重新构建前端和打包。
- 未连接真实 Android 设备验证；真机触控、识别准确性、实际投屏延迟、编码器选项兼容性及真实 CUDA 硬件性能仍需设备验证。
- 配置事务锁保障同进程并发，不能替代多进程文件事务；ZIP 模板与配置写入不提供跨文件磁盘回滚。
- 本轮未进行版本发布或生成新的 Windows 分发包。
